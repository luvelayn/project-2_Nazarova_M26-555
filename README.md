# Primitive DB

Учебная консольная база данных.

## Установка и запуск

Требуется [uv](https://docs.astral.sh/uv/getting-started/installation/).
Из корня проекта:

```bash
uv sync
uv run database
```

## Управление таблицами

- `create_table <имя> <столбец:тип> ...` — создать таблицу.
- `list_tables` — показать список таблиц.
- `drop_table <имя>` — удалить таблицу.
- `help` — показать справку.
- `exit` — выйти. Также доступны `Ctrl+C` и `Ctrl+D` при вводе команды.

Типы столбцов: `int`, `str`, `bool`. Имена состоят из латинских букв, цифр
и символов подчёркивания; имена столбцов не должны повторяться.
Нужно указать хотя бы один столбец. `ID:int` добавляется первым автоматически;
для таблицы только с ID укажите его явно.

Пример команд:

```text
create_table users name:str age:int is_active:bool
list_tables
drop_table users
exit
```

Метаданные хранятся в `data/db_meta.json` относительно директории запуска.
Для работы с той же базой запускайте программу из одной и той же директории.

## Разработка

```bash
uv run ruff check src
uv build
```

Собранные пакеты сохраняются в `dist/`.
